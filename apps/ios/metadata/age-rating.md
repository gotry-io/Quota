# Age rating (Quota iOS)

App Store Connect › Age Rating. Quota is a developer instrument: remaining quota, Usage
totals, and account settings. It has no games, media, user-generated content, ads, or
unrestricted browsing.

Answer every frequency question **None** and every yes/no question **No**. The resulting
rating is **4+**.

## Frequency questions

Values: None / Infrequent or Mild / Frequent or Intense. Select **None**.

| Question | Answer |
| --- | --- |
| Cartoon or Fantasy Violence | None |
| Realistic Violence | None |
| Prolonged Graphic or Sadistic Realistic Violence | None |
| Profanity or Crude Humor | None |
| Horror or Fear Themes | None |
| Mature or Suggestive Themes | None |
| Medical or Treatment Information | None |
| Alcohol, Tobacco, or Drug Use or References | None |
| Simulated Gambling | None |
| Sexual Content or Nudity | None |
| Graphic Sexual Content and Nudity | None |
| Guns or Other Weapons | None |
| Contests | None |

## Yes / No questions

| Question | Answer |
| --- | --- |
| Unrestricted Web Access | No. Sign-in uses `ASWebAuthenticationSession` for GitHub / `quota.gotry.io` only. In-app links open Support, Privacy, and account deletion on that origin. |
| Gambling | No |
| Gambling and Contests | No |
| Loot boxes | No |
| Advertising | No |
| Health or Wellness Topics | No |
| User-Generated Content | No |
| Age assurance / Kids Age Band | Not a kids app; do not set a Kids category. |

## Result

**4+**. No override.

If App Store Connect shows a newer question not listed here, answer None / No unless the
owner decides otherwise. Do not raise the rating for GitHub sign-in or for quota numbers.
