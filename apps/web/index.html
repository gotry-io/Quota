Local by default

02

Remote by choice

Run QuotaCLI on another machine, pair it once, and see its snapshots in QuotaBar.

03

Credentials stay put

The Relay receives normalized quota snapshots—not provider tokens or cookies.

Simple architecture

Your sessions stay on your machines.

QuotaCLI performs read-only collection where each provider is signed in. QuotaRelay stores only normalized snapshots so QuotaBar can bring local and remote quota together.
